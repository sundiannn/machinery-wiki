Ch.1 磁與力

一切都從磁場開始：四大原理

① 電流產生磁場

通電的導線，周圍就有磁場。所有電機的起點。

② 磁通變化 → 電壓 變壓器

穿過線圈的磁通一變化，就感應出電壓（法拉第定律）：$e = -N\,\dfrac{d\phi}{dt}$，$N$ 是線圈匝數，$\dfrac{d\phi}{dt}$ 是磁通變化的快慢

③ 電流在磁場中受力 電動機

磁場裡的通電導線會被推動：$F = ilB\sin\theta$（$\theta$：導線與磁場的夾角）

④ 導線運動 → 電壓 發電機

導線在磁場中移動，兩端就有電壓；三者互相垂直時就是 $e = vBl$

原理②的重點：對靜止的線圈來說，是穿過線圈的磁通「變化」才會產生電壓——磁通再大，只要不變就沒有電壓。（原理④是導線自己在動，是另一種情況。）

Ch.1 磁與力

為什麼電機都用鐵心？

同樣的電流，在電機用的鋼材中建立的磁通是空氣的 2000～6000 倍（相對導磁係數 $\mu_r$）。

所以磁通幾乎都乖乖待在鐵心裡走，可以像電路一樣分析——這就是磁路：

電路磁路
電壓 $V$ 推動電流磁動勢 $\mathfrak{F} = Ni$ 推動磁通
電流 $I$磁通 $\phi$
電阻 $R$磁阻 $\mathfrak{R} = \dfrac{l}{\mu A}$
$V = IR$$\mathfrak{F} = \phi\,\mathfrak{R}$

$l$：磁路長度、$A$：截面積、$\mu$：材料的導磁係數

Ch.1 例題引導（例 1-2）

一小段空氣有多麻煩？

鐵心長 40 cm、中間切開 0.05 cm 氣隙；截面 12 cm²、$\mu_r = 4000$、400 匝；邊緣效應使氣隙有效面積多 5%（12.6 cm²）。$\mu_0 = 4\pi\times10^{-7}$ H/m 是真空（空氣）的導磁係數，鐵心的 $\mu = \mu_r\mu_0$。

1
磁路長什麼樣子？
磁通先後經過鐵心與氣隙 → 兩個磁阻串聯
2
鐵心磁阻？
$\mathfrak{R}_c = \frac{0.4}{(4000)(4\pi\times10^{-7})(0.0012)} \approx 66{,}300$ A·turns/Wb
3
氣隙磁阻？（空氣 $\mu_r = 1$）
$\mathfrak{R}_a = \frac{0.0005}{(4\pi\times10^{-7})(0.00126)} \approx 316{,}000$ A·turns/Wb
4
總磁阻？
串聯直接相加：$\mathfrak{R}_{eq} = 66{,}300 + 316{,}000 = 382{,}300$
5
氣隙要 0.5 T，電流多少？
$\phi = BA$（用氣隙面積），再由 $Ni = \phi\,\mathfrak{R}_{eq}$：$i = \frac{(0.5)(0.00126)(382{,}300)}{400} \approx 0.602$ A

氣隙只有鐵心長度的 1/800，磁阻卻是鐵心的近 5 倍。所以電機中轉子（會轉的部分）與定子（不動的部分）之間的氣隙要越小越好。

Ch.1 第一台電機

同一根棒子：拉它變馬達，推它變發電機

合上開關：電流讓棒子受力加速；跑得越快，棒子自己產生的電壓越大——它和電池方向相反、互相抵消，所以電流越小，最後停在一個穩定速度。

往後拉（加負載）往前推（加外力）
速度變慢變快
能量轉換電 → 機械機械 → 電
角色電動機發電機

例 1-10：無載 120 m/s；推 30 N → 129 m/s（發電機）；拉 30 N → 111 m/s（電動機）。啟動電流 400 A，遠大於運轉時的 30 A。

Ch.2 變壓器

為什麼需要變壓器？

變壓器改變電壓、頻率不變，理想上不改變傳送的功率。電壓升高，電流就變小，電線上浪費的 $I^2R$ 就少。

例 2-1：480 V 發電機經輸電線供電，比較有無 1:10 / 10:1 變壓器。

沒有變壓器有變壓器
線路電流90.8 A9.594 A
負載電壓454 V479.7 V
線路損失1484 W16.7 W

電流約變成 1/10，損失變成約 1/89。

Ch.2 變壓器

理想變壓器：電壓變了，功率沒變

一次繞組接電源，二次繞組接負載

兩組線圈繞在同一個鐵心上，只靠共同的磁通連接。同一個磁通變化，在每一匝感應出一樣的電壓（法拉第定律），所以：

$\dfrac{V_P}{V_S} = \dfrac{N_P}{N_S} = a, \qquad \dfrac{I_P}{I_S} = \dfrac{1}{a}$

  • 電壓乘 $a$，電流除以 $a$ → 輸入功率 = 輸出功率
  • 電壓、電流波形的「步調」（何時到達最高點，稱為相角）不會被錯開
  • 從一次側看，負載的阻抗（交流版的電阻）變成 $a^2$ 倍

Ch.2 變壓器

真實的變壓器不完美——把缺點畫成電路

電抗：線圈對交流電的阻礙，像電阻但不發熱。每個缺點都換成一個電阻或電抗，就能用電路來算：

不完美的地方在等效電路中變成
線圈有電阻（銅損）串聯電阻 $R_P$、$R_S$
有些磁通「漏」到空氣中（漏磁通）串聯漏電抗 $X_P$、$X_S$
沒接負載也要一點電流來建立磁通（磁化電流）並聯磁化電抗 $X_M$
鐵心發熱（磁滯損＋渦流損），補充它要鐵損電流並聯鐵損電阻 $R_C$

磁化電流＋鐵損電流合稱激磁電流；它流過的兩個並聯元件合稱激磁支路。

開路測試：一側開路、加額定（設計上的正常值）電壓 → 電流幾乎只走激磁支路 → 求 $R_C$、$X_M$
短路測試：低壓側短路、調到額定電流 → 幾乎只看到串聯的電阻與電抗 → 求兩側合起來的總值 $R_{eq}$、$X_{eq}$

Ch.3 旋轉磁場

轉動的線圈＝最簡單的交流發電機

線圈在磁鐵中轉動，兩條邊輪流「切過」磁場，一下往這邊、一下往那邊——電壓就一正一負交替，這就是交流電。

$e = \phi_{max}\,\omega\sin\omega t$

$\phi_{max}$：穿過線圈的最大磁通；$\omega$：轉動的角速度

任何真實發電機的電壓都取決於三件事：

磁通 轉速 構造（匝數等）

把三組線圈錯開 120° 放，就得到三組錯開 120° 的電壓——三相電。

Ch.3 旋轉磁場

旋轉磁場：交流馬達的祕密

交流電機分成不動的定子和會轉的轉子。

  • 定子上三組線圈相隔 120°
  • 通入大小相等、相角（步調）相差 120°的三相電流
  • 每個線圈的磁場方向固定、只有大小在變
  • 三個加起來：大小固定（是單一線圈最大磁場的 1.5 倍），而且一直旋轉

定子磁場在轉，轉子磁場就會一直「追著」它轉——這是所有交流電動機的基本原理。

想反轉？把任意兩相對調就好。

Ch.3 旋轉磁場

磁極越多，轉得越慢

兩極電機：電流變化一個週期，磁場剛好轉一圈。四極電機：同樣的 N-S 花紋在一圈中重複兩次，所以一個週期只轉半圈。

$n_{sm} = \dfrac{120\,f_{se}}{P}$

$n_{sm}$：磁場轉速（r/min）；$f_{se}$：電頻率（Hz）；$P$：磁極數

60 Hz 時磁場轉速
2 極（$P = 2$）3600 r/min
4 極（$P = 4$）1800 r/min

小心：$P$ 是「極數」，不是「極對數」。四極電機 $P = 4$。

Ch.4 同步發電機

同步發電機：動 → 電

  • 轉子線圈通直流電（這個電流叫場電流），變成一塊電磁鐵
  • 蒸汽、水力或引擎（原動機）帶著轉子轉 → 旋轉磁場
  • 旋轉磁場掃過定子的三組線圈 → 三相電壓（就是上一章的原理）
  • 「同步」：電頻率和轉速鎖在一起，$n = 120f/P$

$E_A = K\phi\omega$

發電機內部產生的電壓（內生電壓 $E_A$）正比於磁通 $\phi$ 與轉速 $\omega$（$K$ 是由構造決定的常數）。

場電流越大 → 電磁鐵越強（磁通越大）→ $E_A$ 越大。

轉速必須固定（否則頻率會飄），所以調電壓的旋鈕只剩一個：場電流。

Ch.4 同步發電機

接上負載後，電壓為什麼會變？

電流一流出，定子電流自己的磁場會干擾原本的磁場（電樞反應），加上線圈本身的電抗（第 9 頁），合起來叫同步電抗 $X_S$。端電壓＝內生電壓再扣掉同步電抗與線圈電阻造成的電壓變化——但這個「扣」要考慮電流和電壓的步調，所以結果可能變小，也可能變大。

功率因數（功因）用 0～1 的數字表示電流和電壓步調差多少（$=\cos\theta$）：1 叫單位功因（步調一致），0.8 表示錯開了一些。馬達、冷氣這類線圈型（電感性）負載，電流比電壓慢——叫落後；電容性負載電流搶先——叫超前。

例 4-3：無載時端電壓 480 V，場電流不動；接上同樣 60 A 的負載後——

落後：電壓明顯下降；超前：電壓反而上升。同樣的發電機、同樣大小的電流，只因功因不同就差了 125 V → 必須隨負載調整場電流。

Ch.5 同步電動機

同步電動機：同一台機器，反過來用

定子通三相電 → 旋轉磁場；轉子電磁鐵被它拉著，以完全相同的速度旋轉。定子磁場和轉子磁場加起來叫淨磁場；當電動機時，轉子磁場永遠落在淨磁場後面一個角度，叫轉矩角 $\delta$——負載越重，角度越大。

發電機電動機
轉子磁場在淨磁場的前面後面
磁場給轉子的轉矩（扭力，高中的力矩）和轉動方向相反和轉動方向相同
功率機械 → 電電 → 機械
轉速不隨負載改變：從無載到最大轉矩都是 $n = 120f/P$；負載從無到滿，轉速變化 0%（速度調整率 0%）。
脫出轉矩：轉矩角 $\delta = 90°$ 時轉矩最大（通常約滿載的 3 倍）。超過就失去同步、劇烈震動（滑動極）。

還記得第 6 頁的導體棒嗎？同一個道理，現在發生在真正的交流電機上。

Ch.5 例題引導（例 5-3）

轉一顆旋鈕，省下 28% 輸電損失

實功率 $P$（kW）：真正被用掉的功率。虛功率 $Q$（kVAR）：在電線上來回搬運、沒被用掉，但一樣讓電流變大、損失變多。
功因 $= \cos\theta$（$\theta$：電壓與電流錯開的角度），功因 1 叫單位功因。

調同步電動機的場電流：場電流小（欠激）時它像電感、向電網要虛功率；場電流大（過激）時它像電容、能供給虛功率。電流對場電流的圖像字母 V：

工廠接 480 V：兩台感應電動機（工廠最常見的交流馬達，功因落後）100 kW（0.78 落後）、200 kW（0.8 落後），加一台 150 kW 同步電動機。

1
已知 $P$ 和功因，虛功率怎麼算？
$\theta = \cos^{-1}(\text{功因})$，$Q = P\tan\theta$ → 80.2、150、93 kVAR
2
同步電動機 0.85 落後時？
總 $Q = 323.2$ kVAR，功因 $= \cos(\tan^{-1}\frac{Q}{P}) = 0.812$，再由總功率、電壓與功因算出輸電線電流 667 A（功因越接近 1，電流越小）
3
改成 0.85 超前，只有誰變號？
$Q_3 = -93$（它在供給）→ 總 $Q = 137.2$ kVAR，功因 0.957，線電流 566 A

損失 ∝ 電流²：輸電損失少了約 28%，送給負載的實功率一樣多。
