# 例 2-1 輸電要不要變壓器

## 題目（白話版）
一台 480 V、60 Hz 的發電機，經過一條阻抗 $0.18 + j0.24\ \Omega$ 的輸電線，供電給阻抗 $4 + j3\ \Omega$ 的負載〔講義 p.8〕。
- (a) 直接連接時，負載電壓多少？線路損失多少？
- (b) 在發電端加一個 1:10 升壓變壓器、負載端加一個 10:1 降壓變壓器，結果變成怎樣？

## 會用到的概念
- [理想變壓器](../concepts/ideal-transformer.md)：阻抗乘 $a^2$、轉換到另一側
- [交流功率](../concepts/ac-power.md)：損失 $P = I^2R$

## 一步一步來

**(a) 步驟 1：沒有變壓器時，電路是什麼樣子？**
只是一個電源串聯線路和負載，電流處處相同〔講義 p.9〕：

$$ \mathbf{I}_{line} = \frac{480\angle0°}{(0.18 + j0.24) + (4 + j3)} = \frac{480\angle0°}{5.29\angle37.8°} = 90.8\angle-37.8°\ \text{A} $$

**(a) 步驟 2：負載電壓與線路損失**〔講義 p.9〕
- $\mathbf{V}_{load} = (90.8\angle-37.8°)(5\angle36.9°) = 454\angle-0.9°$ V
- $P_{loss} = (90.8)^2(0.18) = 1484$ W

**(b) 步驟 3：有兩個變壓器，怎麼算？——一次消掉一個**
先把負載「轉換」到輸電線那一側：降壓變壓器 $a = 10$，所以 $Z'_{load} = 10^2(4 + j3) = 400 + j300\ \Omega$〔講義 p.10〕。

**(b) 步驟 4：再把整段轉換到發電機那一側**
升壓變壓器 $a = 1/10$，所以 $Z'_{eq} = (1/10)^2(0.18 + j0.24 + 400 + j300) = 0.0018 + j0.0024 + 4 + j3 = 5.003\angle36.88°\ \Omega$〔講義 p.10〕。

**(b) 步驟 5：求電流，再「走回去」**〔講義 p.11〕
- 發電機電流 $\mathbf{I}_G = 480\angle0° / 5.003\angle36.88° = 95.94\angle-36.88°$ A
- 經過升壓變壓器，電流變成 1/10：$\mathbf{I}_{line} = 9.594\angle-36.88°$ A
- 經過降壓變壓器，電流變回 10 倍：$\mathbf{I}_{load} = 95.94\angle-36.88°$ A

**(b) 步驟 6：負載電壓與線路損失**〔講義 p.11〕
- $\mathbf{V}_{load} = (95.94\angle-36.88°)(5\angle36.87°) = 479.7\angle-0.01°$ V
- $P_{loss} = (9.594)^2(0.18) = 16.7$ W

## 答案
| | 沒有變壓器 | 有變壓器 |
|---|---|---|
| 線路電流 | 90.8 A | 9.594 A |
| 負載電壓 | 454 V | 479.7 V |
| 線路損失 | 1484 W | 16.7 W |

## 這題想告訴你什麼
輸電線上的電流變成 1/10，損失（和電流平方成正比）就變成約 1/89，負載電壓也幾乎不掉。這就是電力系統一定要用高電壓輸電、一定要有變壓器的原因〔講義 p.11〕。

> 講義此處註解寫「減少將近 90 %」，依同頁數字計算，損失是降為約 1/89；已記入 [Ch.2 來源摘要](../sources/ch02.md) 的待確認。
