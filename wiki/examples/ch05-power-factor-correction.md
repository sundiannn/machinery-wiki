# 例 5-3 用同步電動機改善功因

## 題目（白話版）
一座工廠接在 480 V 的無限匯流排上，經輸電線供電給三個負載〔講義 p.19〕：
- 負載 1：感應電動機，100 kW、0.78 落後
- 負載 2：感應電動機，200 kW、0.8 落後
- 負載 3：同步電動機，150 kW，功因可調

問：(a) 同步電動機調成 0.85 **落後**時，輸電線電流多少？(b) 調成 0.85 **超前**時呢？(c) 兩種情況的輸電損失相差多少？

## 會用到的概念
- [交流功率](../concepts/ac-power.md)：$Q = P\tan\theta$、$\text{PF} = \cos(\tan^{-1}Q/P)$
- [V 曲線](../concepts/v-curve.md)：過激的同步電動機供給 $Q$
- [功率因數校正](../concepts/power-factor-correction.md)

## 一步一步來

**步驟 1：已知實功率和功因，怎麼求虛功率？**
$Q = S\sin\theta = \dfrac{P}{\cos\theta}\sin\theta = P\tan\theta$〔講義 p.20〕

**步驟 2：(a) 三個負載的虛功率**〔講義 p.20〕
- $Q_1 = 100\tan(\cos^{-1}0.78) = 80.2$ kVAR
- $Q_2 = 200\tan(\cos^{-1}0.80) = 150$ kVAR
- $Q_3 = 150\tan(\cos^{-1}0.85) = 93$ kVAR（落後，取正）

**步驟 3：(a) 加總，求系統功因與線電流**〔講義 p.20〕
- $P_{tot} = 450$ kW，$Q_{tot} = 80.2 + 150 + 93 = 323.2$ kVAR
- $\text{PF} = \cos(\tan^{-1}\tfrac{323.2}{450}) = 0.812$ 落後
- $I_L = \dfrac{450\text{ k}}{\sqrt3(480)(0.812)} = 667$ A

**步驟 4：(b) 同步電動機改成超前——只有 $Q_3$ 變號！**〔講義 p.21〕
- $Q_3 = -93$ kVAR（超前，代表它在**供給**虛功率）
- $Q_{tot} = 80.2 + 150 - 93 = 137.2$ kVAR，$\text{PF} = 0.957$ 落後
- $I_L = \dfrac{450\text{ k}}{\sqrt3(480)(0.957)} = 566$ A

**步驟 5：(c) 損失和電流平方成正比**〔講義 p.21〕
- (a) $P_{LL} = 3(667)^2R_L = 1{,}344{,}700\,R_L$
- (b) $P_{LL} = 3(566)^2R_L = 961{,}070\,R_L$
- 第二種情況的輸電損失少了約 28%

## 答案
| | 同步電動機 0.85 落後 | 同步電動機 0.85 超前 |
|---|---|---|
| 系統虛功率 | 323.2 kVAR | 137.2 kVAR |
| 系統功因 | 0.812 | 0.957 |
| 線電流 | 667 A | 566 A |
| 輸電損失 | 基準 | 少約 28% |

## 這題想告訴你什麼
供給負載的實功率完全一樣，**只是調了同步電動機的場電流**，輸電損失就少了將近三成。這就是工廠願意花較多錢買同步電動機的原因〔講義 p.21–22〕。
