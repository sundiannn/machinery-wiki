# 線性直流機（Linear DC Machine）

## 一句話說明
一根放在軌道上的導體棒，加上電池和磁場，就能示範電動機和發電機的所有行為——而且**同一台機器兩種都能當**。

## 白話解釋
導體棒會自己找到一個「平衡速度」：跑太慢，它就被推快；跑太快，它就被拉慢。有人往後拉它（負載），它就把電池的電能變成動能——是電動機；有人往前推它，它就把動能變回電能——是發電機〔AI 補充〕。

## 正式內容
**構造**：電池、電阻經開關接到兩條無摩擦的平行軌道，軌道間有均勻、指入紙面的磁場，一根導體棒跨在軌道上〔講義 p.31–32〕。

**四個基本方程式**〔講義 p.32〕

$$ \mathbf{F} = i(\mathbf{l}\times\mathbf{B}), \qquad e_{ind} = (\mathbf{v}\times\mathbf{B})\cdot\mathbf{l}, \qquad V_B - iR - e_{ind} = 0, \qquad F_{net} = ma $$

| 符號 | 意義 | 單位 |
|---|---|---|
| $V_B$ | 電池電壓 | V |
| $R$ | 電路電阻 | Ω |
| $i$ | 導體棒電流 | A |
| $e_{ind}$ | 導體棒感應電壓 | V |
| $v$ | 導體棒速度 | m/s |
| $m$ | 導體棒質量 | kg |

**啟動**〔講義 p.33–34〕
1. 合上開關，電流 $i = V_B/R$
2. 電流產生向右的力 $F = ilB$，導體棒加速
3. 速度增加，感應電壓 $e_{ind} = vBl$ 上升
4. 電流 $i = (V_B - e_{ind})/R$ 變小，力也變小
5. 最後 $e_{ind} = V_B$、$i = 0$、$F = 0$，以無載穩態速度 $v_{ss} = V_B/(Bl)$ 前進

**當電動機（加負載）**〔講義 p.35–36〕
- 施加與運動方向相反的負載力 → 減速 → $e_{ind}$ 下降 → 電流上升 → 感應力上升，直到等於負載力，在**較低速度**達到新的穩態
- 電能轉成機械能：$P_{conv} = e_{ind}\,i = F_{ind}\,v$
- 真實直流電動機加負載時行為完全類似，轉換功率為 $P_{conv} = \tau_{ind}\,\omega$

**當發電機（外力推動）**〔講義 p.37–38〕
- 順著運動方向施力 → 加速 → $e_{ind} > V_B$ → 電流反向
- 反向電流產生與運動方向相反的感應力，直到等於外力，在**較高速度**達到穩態
- 機械能轉成電能

**啟動問題**〔講義 p.39〕
- 啟動瞬間 $e_{ind} = 0$，電流可能非常大（例：250 V／0.1 Ω = 2500 A），常超過額定電流 10 倍，會損壞電機；真實交流與直流電機都有類似問題
- 最簡單的解法：啟動時串聯額外的**啟動電阻**，等 $e_{ind}$ 建立後再移除

**弱磁會變快**〔講義 p.41–42〕
- 無載時 $e_{ind} = V_B = v_{ss}Bl$；磁場變弱，穩態速度 $v_{ss} = V_B/(Bl)$ 反而**變快**
- 真實直流電動機的場磁通減弱時，也會轉得更快
